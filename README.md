## 🎨 Features

- 🌙 Premium dark theme with gradient accents
- ✨ Animated particle background
- ⌨️ Typing text effect
- 📱 Fully responsive design
- 🎭 Custom cursor animation
- 🃏 3D tilt effect on project cards
- 📊 Animated skill bars
- 🔢 Counter animations
- 🔍 Project filter system
- 📜 Smooth scroll navigation
- 🖼️ Loading screen animation
- 📬 Contact form with mailto integration

## 📁 Project Structure

```
├── index.html      # Main HTML file
├── style.css       # Stylesheet
├── script.js       # JavaScript animations & interactivity
├── images/         # Profile photos & project images
└── README.md       # This file
```

## 🛠️ Setup

1. Clone this repository
2. Add your profile photo in the `images/` folder
3. Update the `<img>` tag in `index.html` with your photo path
4. Push to GitHub and enable GitHub Pages
